# Yu-Gi-Oh! Master Duel - Agente Autónomo Visual con Cerebro Gemini

Agente autónomo 100% visual y no invasivo (sin inyección de DLLs ni modificación de memoria) para Yu-Gi-Oh! Master Duel.

## Características
- **Captura e Inspección Visual**: Detección de ventana de Master Duel (16:9) mediante Win32 y OpenCV.
- **Cerebro Multimodal Gemini**: Análisis de cartas, tablero, cementerio, efectos y decisiones tácticas óptimas.
- **Navegación PvE / Modo Solo**: Farm automático de gemas, capítulos, puertas y recompensas de historia.
- **Motor de Duelo Inteligente**: Gestión de fases (Main 1, Battle, Main 2, End Phase), respuestas de cadenas y ataques.
- **Protección y Anti-Atasco**: Detección de diálogos emergentes, temporizadores y recuperación segura.
